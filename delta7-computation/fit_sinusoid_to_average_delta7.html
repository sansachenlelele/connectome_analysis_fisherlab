Now try to fit sinusoids to these. Will ignore self-connections because they're weird.

Note that we already have the average inputs and outputs set up so that the self-connections are at the 4th entry (i.e., angle of $\pi$). So instead of adding a phase to the sinusoid we just use $\cos$, which has its minimum at $\pi$. So we will use functions of the form $a + b*\cos(\theta)$.

# Just to sanity check fit using both least squares and nonlinear curve fit
def model(x, a, b):
    return a + b * np.cos(x)

inp_params_cf, _ = curve_fit(model, data_to_fit[:,0], data_to_fit[:,1])
out_params_cf, _ = curve_fit(model, data_to_fit[:,0], data_to_fit[:,2])

X = np.column_stack([np.ones_like(data_to_fit[:,0]), np.cos(data_to_fit[:,0])])
